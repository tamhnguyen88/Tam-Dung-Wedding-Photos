# VIEWME

A modern wedding slideshow experience for Tam & Dung.

## Preview locally

Open `index.html` in a browser, or run a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — slideshow structure and content
- `styles.css` — modern visual design and transitions
- `script.js` — slideshow logic and auto-advance
